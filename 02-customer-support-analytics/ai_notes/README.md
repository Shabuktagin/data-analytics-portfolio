# AI Notes — Customer Support Ticket Analytics

This folder documents how AI tools were used during the development of the Customer Support Ticket Analytics project.

The purpose of these notes is to maintain transparency, record important analytical decisions, and distinguish AI-assisted work from project validation and final interpretation.

## Files in this folder

| File | Purpose |
|---|---|
| `AI_ASSISTANCE_AND_DECISION_LOG.md` | Records AI assistance, project workflow, analytical decisions, and data-quality considerations. |
| `POWER_BI_BUILD_NOTES.md` | Documents the Power BI data model, measures, dashboard design, and outstanding work. |

## Project overview

**Project:** Customer Support Ticket Analytics

**Dataset:** Support Tickets

**Number of records:** 4,000 tickets

**Source:** [Datanemics — Support Tickets Dataset](https://datanemics.com/datasets/support-tickets/)

**Main objective:** Analyze customer support ticket patterns, response and resolution times, priority levels, support channels, queue performance, ticket reopening, and customer satisfaction.

## Transparency statement

AI tools were used as supporting assistants during parts of the project, including planning, code assistance, debugging, analytical interpretation, documentation, and dashboard development.

AI-generated suggestions and outputs should not be treated as independently verified results. Dataset calculations, code execution, business interpretations, and final project decisions should be checked by the project author.

The project author remains responsible for the final analysis and conclusions.
